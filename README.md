# [El papel del trabajador social en el acompañamiento a las familias con cancer]

Proyecto de la asignatura **Informática para el Trabajo Social**, Universidad de Cádiz.

## De qué trata

[Dos o tres frases tuyas: qué problema social abordas y a quién va dirigido.]
Este Trabajo Fin de Grado analiza el impacto psicosocial del diagnóstico de cáncer pediátrico en el núcleo familiar y delimita las funciones clave del trabajador social sanitario. A través de este estudio, se aborda la intervención en situaciones de crisis, la orientación para la tramitación de recursos socioeconómicos y el acompañamiento continuado durante el tratamiento.
